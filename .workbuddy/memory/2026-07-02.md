# 2026-07-02 工作日志

## PC 键鼠模式（用于桌面调试）

### 新增文件
- **`js/pc-mode.js`** (~230 行) - PC 键鼠操控模块

### 控制方案
| 按键 | 功能 |
|:----|:-----|
| WASD | 移动 dolly (相机方向) |
| 鼠标移动 | 视角（yaw 给 dolly, pitch 给 camera） |
| 鼠标左键 | 射击（带 SHOOT_COOLDOWN 冷却） |
| Q | 模拟左手 grip（如来神掌） |
| 1/2/3 | 切换天空：黄昏/白天/夜晚 |
| ESC | 退出 PC 模式回主菜单 |
| 鼠标滚轮 | 微调俯仰角 |

### 接入方式
- index.html 中新增 `.vr-btn-pc` 按钮和 `pc-mode.js` 导入
- animate 循环新增 `else if (pc.isPCMode())` 分支，与 VR 模式平级
- PC 模式下创建虚拟 `STATE.rightController/rightGrip/leftGrip`（Object3D 挂在 camera 下），复用 `shootBullet(controller)` 接口
- 退出 PC 模式回调 `window.__onExitPCMode()`：清理气球、激光关卡、显示主菜单

### 模块改动
| 文件 | 改动 |
|:----|:-----|
| `js/pc-mode.js` | 新建 |
| `js/core.js` | STATE 新增 `pcMode: false` |
| `js/game.js` | GameAPI 导出表补充 `createKnightBalloon, createBalloon, shootBullet` |
| `index.html` | 新增 PC 按钮 + PC 模式 animate 分支 |

### Pointer Lock
- PC 模式启动时调用 `document.body.requestPointerLock()` 锁定鼠标
- ESC 自动解除锁定并退出 PC 模式
