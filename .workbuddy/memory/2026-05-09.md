## Bug 修复

### 1. 后坐力改变枪支基准角度
- **根因**: `ak48BaseRot.x = -20 * PI/180`（-20度），但原始 `rotation.x = -20` 在 Three.js 中为**弧度值**（≈-1145°→模2π≈-66°），转换后仅-20°，角度差约46°
- **修复**: 改为 `-20`（保持与原始代码一致的弧度值），后坐力在弧度基础上加减偏移
- **涉及文件**: `vr.js:219`

### 2. 云朵转场参数调整
- **根因**: 速度6m/s太慢，消失距离22m太近，云朵移动时不够明显
- **修改**: 速度 6→12，消失距离 22→50，重生距离-28→-55
- **新增**: 各参数添加三轴详细注释，说明作用和建议调整范围
- **涉及文件**: `core.js` 云朵转场常量段

### 3. 第二关后无气球出现
- **根因**: 最后一颗气球被消灭后，`checkAllBalloonsDestroyed()` 只在特定路径调用（撞船/被击中），气球可能从其他路径消失（如超出Y范围）导致卡住
- **修复**: `updateBalloons()` 末尾添加 `checkAllBalloonsDestroyed()` 安全兜底，每帧检查条件是否满足
- **移除**: 已删除的 `TRANSITION_WAIT_TIME` 常量从 `game.js` import 中移除

## Bug 修复（二次)

### 4. 安全兜底误触发导致三个连锁 Bug
- **触发链**: `updateBalloons()` 末尾的 `checkAllBalloonsDestroyed()` 每帧执行，游戏开始前 `waveSpawnRemaining=0` 即满足条件 → 误调用 `spawnChoiceCards()` → 连锁引发：
  1. 刚进入游戏选项卡就出现（本该通关后）
  2. 选关时 sessionstart 直接调用了 `attachBuddhaPalmToLeft()` 解锁神掌
  3. 通关后 `clearChoiceCards()` → 1s延时 → `spawnBalloons()` 更新前，安全兜底再次误触发，弹出第二组选项卡（带敌人）
- **修复**: 移除 `updateBalloons()` 末尾安全兜底；移除 `sessionstart` 中直接 `attachBuddhaPalmToLeft()` 的代码
- **验证**: `checkAllBalloonsDestroyed()` 从撞船路径(line 350)和子弹击杀路径(line 396)两条完整链调用，无需额外兜底
- **涉及文件**: `game.js:357-358` 删除, `index.html:336-339` 删除

## Bug 修复（三次）

### 5. 波次过渡改用游戏循环计时
- **问题**: `clearChoiceCards()` 用 `setTimeout` 调用 `spawnBalloons()`，在 PICO 环境下可能不可靠，导致下一波无气球
- **修复**: 
  - 新增 `STATE.nextWaveTimer` 状态字段（`core.js` STATE）
  - `clearChoiceCards()` 设置 `nextWaveTimer = 1.0` 替代 setTimeout
  - `updateCooldowns()` 中逐帧递减，归零时执行 `waveNumber++` + `spawnBalloons()`
  - `sessionend` 重置 `nextWaveTimer = 0`
- **效果**: 倒计时与游戏循环同步，不依赖 setTimeout

### 6. 枪支后坐力方向修正
- **问题**: 后坐力沿 Z 轴移动，但枪支 Y 轴旋转 90°（枪口朝右），导致视觉上"向下"而非"向后"
- **修复**: 位置偏移改为沿 X 轴（-X = 后退缩回），旋转保持 X 轴加法（枪口上跳）

### 7. 云朵转场参数调整
- **问题**: 消失距离短（50m）、重生位置近（-55m），旧云朵未消失前新云朵已同屏
- **修复**: 
  - `TRANSITION_DISAPPEAR_Z = 50 → 300`（云朵远距离消失）
  - `TRANSITION_SPAWN_Z = -55 → -320`（新云朵从远处移入，不与旧云朵同屏）
  - `TRANSITION_SPEED = 12 → 50`（提高移速，整段转场约7-8秒完成）

### 8. 后坐力参数标注 + 方向修正
- **问题**: 后坐力沿 Z 轴导致"左右晃动感"
- **修复**: 位置偏移改为沿 X 轴 - 方向（枪口朝右时 -X = 向后缩回）
- **新增常量**（core.js）:
  - `RECOIL_POS_AMPLITUDE = 0.03`（位置偏移幅度）
  - `RECOIL_ROT_AMPLITUDE = 0.08`（旋转偏移幅度）
  - `RECOIL_DECAY = 0.80`（衰减系数）
- 标注了枪口朝向（rotation.y=PI/2 → 枪口朝右）和后坐力方向说明

### 9. 静态装饰云同步转场移动
- **问题**: 12 朵场景中的静态装饰云在转场时原地不动，破坏了"移山倒海"的转场感
- **修复**: 
  - `game.js` 导入 `clouds` 数组
  - `updateTransitionClouds` phase1：静态云同步向 +Z 移出（速度 = 转场云 × 1.2）
  - phase2 完成时重置静态云到原始位置
  - `startCloudTransition` 记录各云的原始位置

### 10. 波次过渡兜底恢复（带守卫）
- **问题**: 之前的安全兜底（updateBalloons 末尾）因无守卫导致开卡/神掌误触，已移除
- **修复**: 重新加回，但带 `gameStarted && nextWaveTimer === 0` 守卫
  - `gameStarted` 防止游戏开始前误触
  - `nextWaveTimer === 0` 防止 clearChoiceCards→spawnBalloons 的1秒间隙误触
- 同时 `clearChoiceCards` 改用 `nextWaveTimer` 游戏循环计时替代 setTimeout，更可靠
