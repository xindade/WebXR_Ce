# 2026-05-11 工作日志

## 新增: 动画录制工具 anim-recorder.html
- 独立 VR 录制 HTML，不依赖主游戏模块
- **功能**: 将 魔术师.glb 绑定到头显、魔术棒.glb 绑到右手柄，录制动画并导出 JSON
- **文件**: `anim-recorder.html`（579 行）

### 设计要点
- 魔术师可见，位于头显下方 0.3m
- 魔术棒持平于右手柄 `(0,0,0)`
- 录制含自适应降采样（变化小跳过、导出时二次压缩）
- 回放预览功能（线性插值）
- 导出 JSON 含 magician + wand 双轨道数据

## 修复
- 替换 `alert()` 为可见的日志面板 `#log-panel`
- 添加 `log()` 函数支持 info/ok/err 三级日志
- 模型加载、VR 进入等关键路径均有日志输出

## 重构: 镜像模式 + 手柄按键控制
- **魔术师**: 从"绑头上"改为放在用户正前方 3 米，面向用户
  - 用户头转 → 魔术师镜像跟随（Y 轴镜像）
  - 用户右手柄 → 魔术棒镜像映射到魔术师前方空间
- **手柄控制**:
  - 右手柄 **A 键** = 录制/停止
  - 右手柄 **B 键** = 预览/停止
  - 浏览器按钮保留为备选，但主要操作已转交手柄
- **录制数据**: 改为录制魔术师/魔术棒的世界位姿（`mp/mq` + `wp/wq`）
- **导出 JSON**: 双轨道（magician + wand），位置+旋转四元数

## 第2轮修复
1. **镜像方向**: 用户低头→模型低头，用户左转→模型左转（Y轴四元数取反）
2. **魔术棒位置**: 从手柄位置改为放在魔术师同一 3 米前方空间
3. **视觉反馈**: 按键时场景背景闪烁（录=红/预览=紫/导出=蓝），录制时场景偏红、预览偏紫
4. **左手柄**: X 键=导出JSON，Y 键=退出VR（session.end）
5. **日志**: 录制开始/停止均有 log 输出

## 激光关卡: 漆黑降临系统
- **触发**: 玩家碰激光 → `handleLaserHit()` 进入漆黑模式
- **漆黑效果**:
  - 激光气球隐藏、`scene.background=0x000000`、云/月/星/日全部隐藏
  - `blackoutTimer=2s`（冻结的前2秒）
  - `blackoutTimer` 归零后 `restoreAfterBlackout()` 恢复白天+气球动画
  - 剩余1秒: 黑屏渐退 + 瞬回安全区
- **文档**: TECH_README.md §19.5 更新
