📦 WebXR VR 游戏 Capacitor Android 打包指南

将 Three.js WebXR VR 游戏打包为 Android APK

📋 环境要求

工具 版本要求 说明
Node.js 18+ npm 包管理器
Java JDK 17 Capacitor 5.x 需要 JDK 17，8.x 需要 JDK 21
Android SDK 最新 需配置 ANDROID_HOME
Gradle 8.x 通过 wrapper 自动下载

🔧 打包步骤

1 初始化 Capacitor 项目 
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "WebXR热气球" "com.x.webxrce" --web-dir=web
2 添加 Android 平台 
npx cap add android
3 配置 Android SDK 路径
android/local.properties
sdk.dir=C:\\Users\\你的用户名\\AppData\\Local\\Android\\Sdk
4 配置 Maven 镜像（解决下载超时）
android/build.gradle
buildscript {
    repositories {
        maven { url 'https://maven.aliyun.com/repository/google' }
        maven { url 'https://maven.aliyun.com/repository/public' }
        google()
        mavenCentral()
    }
}
allprojects {
    repositories {
        maven { url 'https://maven.aliyun.com/repository/google' }
        maven { url 'https://maven.aliyun.com/repository/public' }
        google()
        mavenCentral()
    }
}
5 配置 Gradle 镜像（华为云加速）
android/gradle/wrapper/gradle-wrapper.properties
distributionUrl=https\://repo.huaweicloud.com/gradle/gradle-8.14.3-all.zip
networkTimeout=120000
6 构建 Web 并同步到 Android 
npm run build          # 构建 Web 项目
npx cap sync android   # 同步到 Android
7 编译 APK 
cd android
JAVA_HOME="C:\Program Files\Java\jdk-17" ./gradlew assembleDebug
8 获取 APK 文件
android/app/build/outputs/apk/debug/app-debug.apk
📱 打包结果约 9.6 MB

⚠️ 常见问题

问题 原因 解决方案
Gradle 下载超时 网络无法访问 services.gradle.org 使用华为云镜像
Google Maven 超时 网络无法访问 dl.google.com 添加阿里云 Maven 镜像
Java 版本不兼容 Capacitor 版本与 JDK 不匹配 Capacitor 5.x 用 JDK 17，8.x 用 JDK 21
Android SDK 路径错误 local.properties 未配置或路径错误 创建并正确配置 sdk.dir
Gradle 解压失败 缺少随机哈希目录名 手动创建 ~/.gradle/wrapper/dists/ 目录
💡 提示：如果是首次构建，建议先确保网络畅通。阿里云和华为云镜像可以解决国内网络访问问题。
