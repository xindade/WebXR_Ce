# 🎈 VR 热气球射击游戏

> Three.js r168 + WebXR | PICO 4 | 模块化架构

---

## 快速启动

```bash
cd /path/to/WebXR_Ce
npx serve -l 3000 -s .
# PICO 浏览器访问: http://<电脑IP>:3000
```

## 游戏机制

1. **波次战斗**: 分阶段生成（前→左+右→全方向），每秒 3 个，同时最多 10 个
2. **气球敌人**: 普通气球（HP=100）+ 骑士气球（HP=500，带血条）
3. **稀有度抽卡**: 清空一波后出现，4 属性 × 4 稀有度（普通/稀有/史诗/传说）+ 金币刷新
4. **如来神掌**: 打完第 0 波解锁，20 倍手掌从天而降清屏
5. **碰撞**: 气球互斥 + 气球-船碰撞 + 撞船扣血（5/个）

## 常见问题

**Q: 启动后页面空白？**  
A: 必须通过 HTTP 服务器打开，不能直接双击 HTML 文件。

**Q: PICO 看不到页面？**  
A: 确保同一 WiFi，检查防火墙 3000 端口。PICO 浏览器支持 HTTP。

**Q: 左侧绿色面板是什么？**  
A: 开发诊断日志面板，显示模块加载状态和运行心跳。

**Q: 模型不出现？**  
A: 检查 `Model/` 目录是否存在对应 `.glb` 文件。
